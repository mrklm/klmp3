Aide & mode d’emploi

---

🪗 🪕 🎷 🎻  Qu’est-ce que KLmp3 ?  🪘 🎹 🎤 🎺

KLmp3 est un outil simple et robuste permettant  
d’extraire le son de contenus en ligne.

🎯 Plateformes supportées  
→ YouTube & Twitch 💾

📌 Vous fournissez une URL  
🪠 KLmp3 s’occupe de la technique  
🔊 Vous récupérez un fichier audio prêt à l’écoute 🎶

---

🛠️ Comment ça fonctionne ? (principe général)

1. Vous collez une URL  
2. KLmp3 détecte automatiquement la plateforme 🤖  
3. KLmp3 télécharge le meilleur flux audio disponible 🪠  
4. KLmp3 convertit vers le format choisi (mp3 par défaut) ⚙️  
5. Vous obtenez un fichier audio final 📦️

---

🎬 Extraire le son d’un contenu unique

🎯 Objectif  
👉 Extraire le son d’une seule vidéo ou VOD

🧭 Procédure  
1. Onglet Général  
2. Coller l’URL YouTube ou Twitch  
3. Cliquer sur ▶️ Démarrer  

📈 Progression affichée en temps réel  
🧹 Nettoyage automatique des fichiers temporaires

---

🎬 Extraire le son d’une playlist

🎯 Objectif  
📂 Extraire le son de plusieurs contenus

🧭 Procédure  
1. Coller l’URL d’une playlist  
2. Activer le mode Playlist  
3. (Optionnel) définir une limite  
4. ▶️ Démarrer  

Chaque élément est :  
- téléchargé séparément 🔼  
- converti individuellement ⚙️  
- annulable à tout moment ⛔  
- rangé dans un dossier au nom de la playlist 📂

---

🎧 Choisir le format audio de sortie

Formats disponibles dans l’onglet Options :

MP3 → universel, compatible partout 🌍  
M4A / AAC → excellente qualité, fichiers légers ✨  
OPUS → très haute qualité à débit réduit 🚀  
OGG → format libre et efficace 🟢  
FLAC → qualité maximale, sans perte 💎  
WAV → audio brut, non compressé 🎚️  

KLmp3 sélectionne automatiquement le meilleur flux audio disponible  
puis effectue la conversion vers le format choisi 🔄

Options de normalisation à cocher dans l'onglet général ✅️
choix du type de normalisation dans l'onglet options ⚙️

👉 Retrouver facilement les fichiers générés

  `klmp3-AAAA-MM-JJ` 📅  
- Le dossier est placé sur le Bureau

---

🎼 Titres et numéros de piste (important)

KLmp3 ne modifie **jamais** le nom des fichiers.

Il travaille uniquement sur les métadonnées internes (tags audio).

🗂️ Nom de fichier ≠ Titre  
Le nom de fichier sert à l’organisation humaine.  
Le Titre est une métadonnée utilisée par les lecteurs (Kodi, etc.).

🔢 Numéro de piste  
Utilisé pour le classement correct des morceaux dans un album.

---

⚙️ Options → Métadonnées automatiques

Par défaut, KLmp3 applique un comportement sécurisé :

☑️ N° de piste = N° de fichier  
→ extrait automatiquement 01, 02, 03… depuis le nom

☑️ Titre = Nom du fichier  
→ déduit le titre à partir du nom du fichier

Exemple :

01 - Ma chanson.mp3  
→ Titre : Ma chanson  
→ N° de piste : 1  

Ces options peuvent être désactivées dans l’onglet Options  
pour saisir les valeurs manuellement.

---

🧠 En résumé (métadonnées)

🗂️ le nom de fichier n’est jamais modifié  
🎵 le Titre sert à l’affichage  
🔢 le N° de piste sert au classement  
📚 pour une compatibilité parfaite (Kodi), les deux doivent être renseignés

🔩  Bonus pour les Geeks 🔬


🔎 mais alors qu’est-ce que quoi comment ?

 🔍️ 🕯️ Sous le capot de KLmp3 :
 
  mais qui fait quoi donc ? 📋️ 

  🐍 yt-dlp — le cerveau explorateur

  🧭 yt-dlp est le descendant moderne de youtube-dl. 

  👉 Son rôle : 
  
  🧠 analyser les pages YouTube / Twitch 
  🔍 comprendre où se cachent les flux audio 
  🧩 contourner les changements réguliers de structure 
  🍪 gérer les cookies (vidéos privées, age-restricted, etc.) 
  📜 gérer playlists, VODs, formats multiples… 
  Dans KLMP3, yt-dlp est utilisé : soit comme module Python (yt_dlp) 
  🐍 → mode recommandé soit comme binaire externe (secours) 
  🧰 💡 yt-dlp ne convertit pas vraiment l’audio :
   il télécharge la meilleure source disponible.
   
    ---
    
  🎞️ ffmpeg — l’alchimiste audio
  
  🔥 ffmpeg, c’est le couteau suisse multimédia ultime. 
  Un outil capable de transformer presque n’importe quoi
   en presque n’importe quoi.

  👉 Son rôle: 
  
  🎧 convertir l’audio téléchargé vers le format choisi :
   MP3 / M4A (AAC) / OPUS / FLAC / OGG / WAV 
   🎚️ appliquer les réglages de qualité / bitrate 
   ✂️ extraire uniquement la piste audio (pas de vidéo) 

   Exemples :
   
    MP3 → libmp3lame 
    AAC → aac ou aac_at (macOS 🍏) 
    OPUS → libopus FLAC → compression sans perte 
    
    💥 Sans ffmpeg, pas de conversion, juste des fichiers bruts.
    
     --- 
     
     🔎 ffprobe — l’inspecteur discret 🕵️ 
     ffprobe est le petit frère silencieux de ffmpeg.
     
    👉 Son rôle :

    🧾 analyser un fichier multimédia 
    🔍 détecter codecs, flux audio/vidéo, durée, métadonnées 
    🧪 vérifier ce que ffmpeg sait (encodeurs disponibles) 
    
    Son rôle:
    
    Savoir si certains encodeurs sont présents 
    adapter automatiquement le comportement
    (ex : AAC sur macOS) 🧠 ffprobe ne modifie rien. 
    Il observe. Il juge. Il rapporte. 
    
    ---
    
     🦕 Deno — le solveur de casse-têtes JavaScript 
     💩 Depuis quelques temps, YouTube adore 
     compliquer la vie des téléchargeurs 
     🧩 Certaines vidéos nécessitent désormais : 
     
     🧠 l’exécution de JavaScript dynamique 
     🛡️ des JS challenges (EJS) 
     
     👉 Deno est un runtime JavaScript moderne (alternatif à Node.js),
      sécurisé et autonome. 
      
      Dans KLmp3 : 
      
      Deno permet à yt-dlp de résoudre ces défis 
      JavaScript sans ouvrir de navigateur 
      sans interface graphique sans espionnage 😇 

      📦 Si Deno est présent :
      
      👍 meilleure compatibilité YouTube 
      🚀 moins d’erreurs “Video unavailable” 
      
      📉 S’il est absent : 
      
      KLmp3 continue de fonctionner mais certaines vidéos peuvent échouer
       (mode dégradé) 
      
      --- 
      
      🧰 Pourquoi des outils “embarqué́s” ? 
      
      KLmp3 peut fonctionner avec : des outils installés dans le système 🧭 
      ou des outils embarqués dans tools/<platform>/ 

      📦 Avantages de l’embarqué : 
      
      🧊 comportement identique sur toutes les machines 
      🚫 pas de dépendance au système 
      🛠️ pas besoin d’installation manuelle 
      🎯 moins de “ça marche chez moi”
      
       --- 
       
       🧠 En résumé: 
       
       🐍 yt-dlp → trouve et télécharge l’audio 
       🎞️ ffmpeg → convertit l’audio 
       🔎 ffprobe → inspecte les formats et capacités 
       
       🦕 Deno → aide yt-dlp à passer les pièges JavaScript
